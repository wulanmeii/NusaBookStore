# 📚 NusaBookstore

Aplikasi toko buku berbasis **Flutter** yang dikembangkan untuk memenuhi tugas mata kuliah Pemrograman. Aplikasi ini mengimplementasikan konsep *State Management* menggunakan package `provider`, katalog produk interaktif, keranjang belanja, serta fitur *Theme Switching* (Light/Dark Mode).

## 🚀 Fitur Utama
- **Katalog Buku**: Menampilkan daftar buku lengkap dengan gambar, judul, penulis, dan harga.
- **Keranjang Belanja (Cart Management)**: Menambahkan item ke keranjang dan menghitung total secara real-time menggunakan `ChangeNotifier` & `Provider`.
- **Theme Switching**: Fitur ubah tema aplikasi antara mode terang (*Light Mode*) dan gelap (*Dark Mode*).
- **Responsive Web Support**: Berjalan dengan mulus di platform Web menggunakan Flutter Web Server.

## 🛠️ Teknologi yang Digunakan
- **Flutter & Dart** (Framework utama)
- **Provider Package** (State Management)
- **Unsplash API** (Sumber gambar katalog dinamis)
